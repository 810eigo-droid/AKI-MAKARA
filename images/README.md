# images フォルダ

LPで使う画像の置き場所。

**ファイル名・サイズ・書き出し基準の一覧は、リポジトリトップの [README.md](../README.md) にまとめてあります。**
（二重管理して食い違うのを避けるため、詳細はそちらの1箇所だけに置いています）

---

## このフォルダでのアップロード手順

1. パンくずが `AKI-MAKARA / images` になっていることを確認
2. 右上の `Add file ▾` → `Upload files`
3. 画像をドラッグ＆ドロップ
4. 画面下の `Commit changes`

**同じファイル名なら、確認なしにそのまま差し替わります。** 古いファイルを消す必要はありません。

---

## 最低限の注意

- 形式は **WebP**（`.webp`）。https://squoosh.app/ で Quality 80
- **横長にしない。** スマホで文字が読めなくなります
- 1枚150KB以下（FVのみ250KBまで）
- ファイル名は一覧のとおりに。1文字違うと表示されません
