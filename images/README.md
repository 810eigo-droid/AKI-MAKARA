## 共通ルール

| 項目 | 基準 |
|---|---|
| 形式 | **WebP**（`.webp`）。拡張子まで含めて名前を合わせる |
| 品質 | 80 |
| 容量 | 1枚 **150KB以下**。FVだけ250KBまで |
| 変換 | https://squoosh.app/ で WebP・Quality 80 → Download |

**幅は「表示される幅の3倍」が目安です。** スマホは390px幅なので、1170px前後あれば十分です。

## 個別の注意

### `fv.webp`
GPTで出せる最も縦長の比率は **1024 × 1536（2:3）** です。それ以上縦長にはできません。

### `aki.webp`
**AI生成不可。真果楽様の実写を使ってください。** 顔の信頼性がそのまま成約率に影響します。
正方形にトリミングし、顔が中央にくるようにしてください。円形に切り抜かれて表示されます。

### `check.webp` / `gift-*.webp`
文字が画像に焼き込まれています。**文言を変更する場合は画像の作り直しが必要**です。
誤字がないか、アップロード前に必ず確認してください。

### `ogp.webp`
LINEやX（Twitter）でURLを共有したときに出るサムネイル画像です。
使うときは `index.html` の `<head>` にOGP設定の追記が必要なので、その時点でご相談ください。

## アップロード手順（GitHubの画面から）

1. この `images` フォルダの中に入る（パンくずが `AKI-MAKARA / images` になっていること）
2. 右上の `Add file ▾` → `Upload files`
3. 画像をドラッグ＆ドロップ
4. 画面下の `Commit changes`

1分ほどで公開URLにも反映されます。反映されないときは `Ctrl + F5`。
