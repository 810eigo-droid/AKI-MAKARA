## 現状：提案サンプル

`index.html` は既存LP（`akimakara.com/shiawase2`）の改善提案として作成したものです。
ページ全面に `SAMPLE` 透かしと左上バッジを表示しています。
`<body class="is-sample">` から `class="is-sample"` を消すだけで両方消えます（630行目）。

### 差し替えが必要な箇所

- **CTAリンク** — `href="#entry"` を公式LINEの友だち追加URLに差し替え
- **プロフィール写真** — `.pf-photo` のプレースホルダー（"A"の円）を実際の写真に
- **実績数値** — 鑑定実績 / 活動年数 / 満足度（現在は仮の数値）
- **お客様の声** — 3件すべてサンプルテキスト。実際にいただいた声に差し替え
- **特典の通常価格** — `12,800円相当` の表記
- **フッターリンク** — 運営者情報 / プライバシーポリシー / お問い合わせ

### 既存LPからの主な変更点

1. 導線をLINE一本に統一（メールフォームとの二重導線を解消）
2. CTAをFV・中盤・最終・追従バーの4箇所に配置
3. 紫背景に白抜き細字 → 白カード＋濃色テキストで可読性を確保
4. 特典を画像のみ → 見出し＋説明文で内容が伝わる形に
5. プロフィール・実績・お客様の声を追加し信頼性を補強
6. FAQセクションを新設（無料の根拠・初心者不安・通知頻度など）
7. スマホ基準で設計（FV内にCTAが収まる高さに調整）
