## 書き出しの基準

| 項目 | 基準 |

## 画像ごとの注意

### 横長画像は使わないこと

スマホでは画像が横幅に合わせて縮むため、**横長にすると文字が読めなくなります。**

| 比率 | スマホでの文字サイズ |
|---|---|
| 1122 × 1402（縦長） | 約 9〜11px |
| 1672 × 941（横長） | **約 6px** ← 読めません |

### `fv.webp`
GPTで出せる最も縦長の比率は **1024 × 1536（2:3）** です。それ以上縦長にはできません。

### `aki.webp`
**AI生成不可。真果楽様の実写を使ってください。** 顔の信頼性がそのまま成約率に影響します。
正方形にトリミングし、顔が中央にくるように。円形に切り抜かれて表示されます。

### `profile.webp`
比率の指定はありません。横長でも縦長でも、そのままの形で表示されます。

横長（1672 × 941）はスマホで文字が約6px相当まで縮むため使えません。
**941 × 1672 などの縦長で作ってください。**

**⚠️ この画像には実績数値（1,200名+ / 12年 / 96%）が焼き込まれています。これは仮の数字です。**
実データが確定したら画像ごと作り直してください。

### `closing.webp`
**背景が濃い紫のため、セクション背景との境目が出やすい画像です。**
アップ後に画像の端の色を測って背景を合わせるので、入れ終わったら一声かけてください。

### `voice-01〜03.webp`
**円形に切り抜かれ、58pxで表示されます。** 顔が中央にくるようにしてください。
文字は入れないこと。500×500 で十分です（1枚40KB以下が目安）。

実在しない人物のイラストを使う場合、**「イメージです」等の断りは不要ですが、
声の内容自体は必ず実際にいただいたものにしてください。**

### 文字入り画像すべて
文言を変更する場合は**画像の作り直しが必要**です。誤字がないか、アップロード前に必ず確認してください。

## アップロード手順（GitHubの画面から）

1. `images` フォルダの**中に入る**（パンくずが `AKI-MAKARA / images` になっていること）
2. 右上の `Add file ▾` → `Upload files`
3. 画像をドラッグ＆ドロップ
4. 画面下の `Commit changes`

1分ほどで公開URLに反映されます。反映されないときは `Ctrl + F5`。

# 既存LPからの主な改善点

`index.html` は既存LP（`akimakara.com/shiawase2`）の改善提案として作成したものです。

1. **導線をLINE一本に統一** — メールフォームとの二重導線を解消（最大の離脱要因）
2. **CTAを4箇所に配置** — FV / 中盤 / 最終 / スクロール追従バー
3. **可読性の確保** — 紫背景に白抜き細字 → 白カード＋濃色テキスト
4. **特典を言語化** — 画像のみ → 内容が伝わる形に
5. **信頼要素を追加** — プロフィール・実績・お客様の声
6. **FAQを新設** — 無料の根拠・初心者の不安・通知頻度など5問
7. **スマホ基準で設計** — 390px幅でCTAが1画面目に収まる高さに調整
